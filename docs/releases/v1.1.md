## What's new in 1.1

- **Sound board (S.Play):** a WAV from the SD card on each of the top row's
  first four pads, played over the loops. Each one starts the moment its pad
  is pressed (its first second is kept in memory) and streams the rest from
  the card, so a WAV can be any length. One plays at a time: a press stops
  what plays. Play modes: one-shot, toggle or gate. **To loops** puts the
  board on the input, so a take records it. The board is kept on the card
  (`Looper/soundboard.txt`).
- **New project (File, F7 twice):** clears every loop and the track names;
  F1 then saves it as a new numbered project.
- **Length lock (Left / Right on the home page):** set the selected track's
  loop length before a take, in bars (hold + encoder, or a tap is a bar less /
  more). One Rec press then records exactly that long.
- **Mode bar stays open (F5):** try several playback modes in a row; the lit
  one again closes it.
- The F-key labels on the sample loader no longer show the performance
  effects while performance mode is on.
- The project is now called **Retrack**.

### Note on memory

The sound board takes 0.84 MB of the loop memory: a track now holds about
20.4 s of stereo in RAM (was 21.5 s). With an SD card, longer takes go on to
the card from about 18.2 s (was 19.5 s), up to 5 minutes as before.
